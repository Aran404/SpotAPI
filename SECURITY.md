# Security policy

## Supported versions

Security fixes are made against the latest SpotAPI 2.x release. The synchronous
`1.2.8` line remains available for migration compatibility but is not actively
developed.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email
[aran.inbox.personal@gmail.com](mailto:aran.inbox.personal@gmail.com) with:

- the affected SpotAPI and Python versions;
- the impact and the conditions required to reproduce it;
- a minimal reproduction with all credentials and private identifiers removed;
- any suggested mitigation, if known.

Never send a live Spotify cookie, access token, password, recovery code, or other
account secret. If evidence requires sensitive material, describe it first and
wait for a safe exchange method.

You should receive an acknowledgement within seven days. Please allow time to
confirm the report and prepare a coordinated fix before public disclosure.
SpotAPI does not currently operate a paid vulnerability-reward program.
