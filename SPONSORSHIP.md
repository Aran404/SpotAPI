### Exclusive integration partnerships

For partners whose services are genuinely useful to SpotAPI developers, we can offer more than a logo: **a documented, optional, officially maintained provider integration with category exclusivity**. The partner becomes the sole *official turnkey adapter* in the agreed integration category for the contract term, alongside a featured README placement. This is distinct from the $199 **Category Exclusive** tier, which covers **paid README advertising only**.

**Example (illustrative, not an existing sponsorship):** SpotAPI already exposes the provider-neutral async `CaptchaSolver` protocol for certain account and password-recovery operations. A CAPTCHA service could sponsor the project's only officially maintained provider adapter for that protocol. Developers would supply their own service API key and explicitly select the adapter. Custom solvers and the provider-neutral protocol would continue to work; no commercial provider would be required to use SpotAPI.

Commercial terms are quoted after technical review and normally include:

- **One-time development fee:** adapter implementation, tests, installation instructions and usage example.
- **Ongoing exclusivity fee:** mutually agreed category and surfaces (for example, the official adapter and paid README placement), with a clearly defined term and renewal price.
- **Maintenance scope:** what compatibility fixes and support are included, and how work outside that scope is billed.

No exclusivity is perpetual or implied beyond the written term. An expired sponsorship removes promotional placement and exclusive status, **not released code or user functionality**. We will not remove compatibility with custom provider implementations, guarantee third-party challenge acceptance, or claim a provider is necessary when it isn't. Development and exclusivity start only after separate technical and commercial agreement.

## Placement and editorial standards

Sponsor listings belong in the README **after the product introduction and usage examples**, not above installation or in the API reference. The README remains useful to developers first.

- Every paid placement is clearly labeled **Sponsor**. Affiliate links, when used, are disclosed.
- Products must be relevant to the project's developer audience. We may decline misleading, unsafe, or unrelated promotions.
- Sponsorship does not imply endorsement by Spotify, approval of the sponsor's claims, or a requirement to use any paid service with SpotAPI.
- Category exclusivity covers only the agreed category and **paid README placements** for the stated term. It does not exclude open-source alternatives, user-supplied providers, neutral documentation, or unpaid references.
- Exclusive integration sponsorship may reserve one **official maintained adapter** in an agreed category during the contract, but never restricts the public protocol, third-party code, custom implementations, or compatibility with existing users. Technical integrations require separate review, tests, documentation and maintenance terms. They must be opt-in, keep credentials under user control, and never silently make paid requests. Sponsorship does not buy changes to core API semantics or hidden preferential behavior.
- When a sponsorship ends, its advertising ends. It does not remove already released functionality or affect users' access to the library.
