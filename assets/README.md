# SpotAPI identity

`logo.svg` is the standalone symbol, separated from the supplied wordmark without
redrawing its paths or changing its colours. Use it with ordinary, separate text.
`logo-mono.svg` and `logo-inverse.svg` provide single-colour variants. The four
`spotapi-*.svg` files preserve the supplied originals.

The identity uses turquoise `#0FC9C5`, blue `#0E7EAE` / `#4DA3D1` and ink `#0E0B16`.
Studio pairs those with warm paper and a restrained coral accent. Do not place the
full symbol-and-wordmark artwork inside a small icon container.

`social-preview.png` is the 1280×640 repository sharing card. Upload that file in
the repository's **Settings → General → Social preview** panel after changing it.
